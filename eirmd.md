
# Portfólio do Professor Leonardo

Portfólio educacional dedicado ao componente curricular de
Língua Espanhola.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

1. Abra a pasta do projeto no Visual Studio Code.
2. Abra o arquivo `index.html` no navegador.
3. Opcionalmente, utilize a extensão Live Server para visualizar
   as alterações durante o desenvolvimento.

## Personalização

- Atualize a apresentação e os dados profissionais do professor.
- Adicione informações reais sobre formação e experiência.
- Substitua os projetos sugeridos por atividades realizadas.
- Atualize o e-mail de contato no arquivo `index.html`.
- Ajuste os conteúdos de acordo com a etapa de ensino.

Os dados profissionais não fornecidos foram omitidos para evitar
a inclusão de informações pessoais inventadas.
